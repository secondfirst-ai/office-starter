# Shipped

Everything that left the company, one row each.

**Counts:** things other people can see, use or answer. An email sent, a page live, a post up, a handout delivered.
**Doesn't count:** internal files and pages, proposals, summaries. Follows, likes and other account actions.

**Rules**

- Whoever lets it out records it, right then. Search first, in case someone else already did. Others who helped go in brackets.
- A batch sent together is one row with a count and a range.
- When something comes back (a reply, a booking, a link, a mention), add it to the same row. If nothing came back, leave it empty.
- A fix or update to something already out counts as a `page`. `article`, `guide` and `template` are only for new ones.
- Use only the kinds below. <Name> decides new ones.

**Kinds:** cold email, letter, post, reply, page, template, guide, article, code
